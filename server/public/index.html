3D Web Visual Encoding

1. Spokes = Spaces (Life Areas)

Each space extends as a radial spoke of the spider web with its assigned color. The first space points directly up (12 o'clock), continuing clockwise.

2. Rings = Urgency (Time Bands)

NOW (Center) ➔ THIS WEEK ➔ THIS MONTH ➔ LATER (Outer)

3. Depth (Z-Axis) = Priority

High priority floats closest to you with vibrant glow. Medium sits on the baseline. Low sits deeper into the fog.

4. Node Shapes = Type

Task (Circle)
Idea (Diamond)
Question (Hexagon)
Goal (Star)

5. Silk Strands (Connections)

Explicit links: Bright, curved silk threads connecting dependent nodes.
Shared keywords: Dotted silk threads. When a node is selected, connected threads illuminate with flowing particle energy.
